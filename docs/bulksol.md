# BulkSOL — BULK Exchange Native Liquid Staking Token

BulkSOL is BULK Exchange's liquid staking token (LST) on Solana. It earns yield from multiple sources, one of which — BULK Exchange trading fee revenue — does not exist on any other Solana LST.

> **Sources:** Fee percentages from [docs.bulk.trade/bulk-exchange/fees](https://docs.bulk.trade). APY figures are variable and market-dependent. The base staking APY shown on Exponent Finance was 3.71% as of May 31, 2026.

## Yield Sources

| Stream | Source | Status |
|--------|--------|--------|
| 1 | Base Solana staking rewards | Live (variable APY) |
| 2 | MEV tips from Solana block production | Live |
| 3 | 12.5% of all BULK Exchange taker fees | Activates at mainnet |
| 4 | Season 1 AURA weekly allocation | Live until mainnet |

Stream 3 accrues to validators who run the BULK Exchange network. BulkSOL holders earn it because they are staked with the BULK validator set. The 12.5% figure is confirmed in [docs.bulk.trade/bulk-exchange/fees](https://docs.bulk.trade).

Stream 3 is zero until mainnet launches and is proportional to actual trading volume — it is not guaranteed.

---

## How BulkSOL Works

BULK validators run a `bulk-agave` binary alongside their standard Solana validator. These share identity keys and Solana stake weights, so BulkSOL stakers back the same validator set that secures BULK Exchange.

BulkSOL is an appreciating-rate token — yield accrues into the token's exchange rate rather than as separate payments. When you redeem BulkSOL for SOL, you receive more SOL than originally deposited.
